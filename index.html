Attention Scanner

2025–2026

A real-time computer vision system that tracks multiple people through a webcam and classifies each one as attentive, distracted, drowsy or yawning, scoring every session out of 100. Started as a 24-hour hackathon build and I've been developing it ever since.

  • Eye and mouth aspect ratios from a 468-point face mesh, plus head pose solved with OpenCV solvePnP
  • Hysteresis thresholds and minimum-duration gates so a blink never registers as drowsiness
  • Custom tracker whose search radius widens as a face stays missing, so people keep their ID after brief occlusion
  • Ships as both a desktop OpenCV app and a FastAPI service behind a React dashboard

Smart ASHA Connect

2026

A healthcare platform for ASHA workers in rural India — patient records, visit history, vitals tracking and emergency dispatch. I built the Python service that scores each patient's health risk and explains the result in plain language.

  • XGBoost classifier scoring risk from seven clinical readings, returning a level with its confidence
  • Falls back to deterministic clinical rules if the model fails, so the system still gives an answer
  • Validates physiological ranges before inference to reject impossible readings
  • Runs Llama 3 locally through Ollama rather than a paid API — cheaper, and patient data never leaves the machine
